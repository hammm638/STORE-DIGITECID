Pakai dengan AI

Mau membuat bot atau situs dengan bantuan ChatGPT, Claude, atau AI lain? Salin spesifikasi di bawah dan tempel ke chat AI-nya. Isinya semua endpoint, parameter, aturan, dan format error, ditulis ringkas supaya AI tidak mengarang endpoint.

Prompt siap pakai = instruksi untuk AI + spesifikasi. Setelah ditempel, tulis apa yang kamu mau, misalnya "buatkan bot Telegram order nomor pakai Node.js".

Mulai cepat

  1. Login ke situs, buka menu titik 3, pilih API dan dokumentasi, lalu buat API key.
  2. Isi saldo lewat menu Deposit di situs atau POST /deposits.
  3. Kirim permintaan dengan header X-API-Key.

Header alternatif: Authorization: Bearer dtz_.... Key hanya tampil sekali, server menyimpan hash-nya. Membuat key baru mematikan key lama. Jangan taruh key di front-end atau repositori publik.

Aturan penting

    Format respons

    Sukses: { "ok": true, "data": { ... } }
Gagal : { "ok": false, "error": { "code": "insufficient_balance", "message": "Saldo tidak cukup", "balance": 2000, "price": 3000 } }

    Batas per API key: 60 GET per menit dan 20 POST per menit. Header X-RateLimit-Limit, X-RateLimit-Remaining, dan saat terlampaui Retry-After (detik, status 429).

    Alur order

    Beli nomor dan terima OTP

    1. PilihGET /countries lalu GET /services. Ambil code negara, serta id dan provider layanan.
    2. OrderPOST /orders. Saldo terpotong, kamu dapat number yang berlaku sekitar 20 menit.
    3. Tunggu OTPPolling GET /orders/{id} tiap 5 detik sampai otp bukan null.
    4. Selesai atau batalOTP tidak datang? POST /orders/{id}/cancel. Order batal atau kedaluwarsa dikembalikan otomatis, sekali saja.
    Setelah OTP masuk, order dianggap selesai: saldo tidak kembali dan cancel membalas 409 otp_received. status diteruskan dari penyedia (waiting, canceled, expired). refunded: true berarti saldo sudah kembali.

    Isi saldo QRIS

    1. BuatPOST /deposits dengan nominal. Kalau qr_link berisi gambar (data URI), tampilkan.
    2. Ambil QRKalau qr_link null, panggil GET /deposits/{id}/qr. Status 202 + qr_pending berarti ulangi tiap 5 detik (10 sampai 60 detik).
    3. CadanganKalau tetap kosong dan qr_error terisi, buka pay_url di browser untuk bayar.
    4. KonfirmasiPolling GET /deposits/{id} sampai status berhasil. Saldo bertambah otomatis satu kali.
    Gambar dari /qr adalah screenshot halaman bayar 420 x 620 piksel, bukan QR polos. Potong dari crop.top sepanjang crop.height piksel sebelum ditampilkan.

    Endpoint

    Ketuk satu endpoint untuk melihat parameter, contoh permintaan, dan contoh respons.

    Kode error

    HTTPcodeArti dan tindakan
    400invalid_param, invalid_jsonParameter atau body salah. Baca message.
    400upstream_rejectedPenyedia menolak (misalnya stok habis). Saldo tidak terpotong.
    401invalid_api_keyKey tidak dikirim, salah, atau dicabut.
    402insufficient_balanceSaldo kurang. Respons memuat balance dan price. Minta user deposit.
    403account_bannedAkun diblokir.
    404not_found, service_unavailableEndpoint, order, atau deposit tidak ada, atau layanan habis. Muat ulang daftar layanan.
    409otp_received, out_of_stock, maintenanceOTP sudah masuk (tidak bisa cancel), stok habis, atau negara sedang maintenance.
    409request_in_progressIdempotency-Key yang sama masih diproses.
    409deposit_closedDeposit sudah berhasil, batal, atau kedaluwarsa. QR tidak dibuat.
    429rate_limitedTunggu sesuai retry_after detik.
    5xxupstream_unreachable, upstream_invalid, database_errorGangguan server atau penyedia. Aman diulang. Order yang gagal dibuat dikembalikan saldonya.
